AI Social Media Carousel Automation

Curated Italian Editorial Copywriting, Transparent 3D Hero Isolation & Headless High-DPI Multi-Slide Publishing

An autonomous end-to-end generative pipeline that ingests topics via chat, synthesizes structured editorial social media carousel decks in Italian, generates centered 3D hero assets with alpha background isolation, renders high-DPI viewports for Instagram (4:5) and TikTok (9:16 safe areas), powers live interactive review loops in Telegram, and executes an unconditional ephemeral purge leaving zero residual system footprint.

⚠️ The Content Production Bottleneck

Crafting luxury social media carousels manually is slow, fractured, and tedious. Marketers struggle with writing concise editorial copy adhering to strict character budgets, generating and cleanly cutting out 3D subjects from white backgrounds, adapting layouts across Instagram portrait (4:5) and TikTok vertical (9:16) safe margins, and enduring endless mockup revisions inside disjointed chat channels.

💡 The Automated Architecture

An industrial-grade autonomous orchestration pipeline that pairs Google Gemini with cloud generative vision and neural segmentation (rembg). It delivers interactive Telegram review dashboards with in-place mockup refreshing, theme toggling (Light/Dark), high-DPI headless browser compositing, and automated multi-page photo album delivery backed by guaranteed ephemeral disk cleanup.

🔬 Technical Deep Dive & Business Logic Flow

Chronological pipeline execution sequence decomposing the system into 7 mission-critical operational phases, decision branches, interactive review loops, and guaranteed purge protocols.

STAGE 1 · INGESTION & VALIDATION [GATEWAY: TELEGRAM / REST]

Ingestion & Input Validation

User submits a creation request containing a topic string. The gateway validates that the payload is non-empty. If the destination channel is unassigned, it prompts the user with an interactive selector. Upon confirmation, any lingering session is purged for state idempotency.

Channel Constraint Locking

Locks aspect ratio bounds: Instagram 1080×1350 (4:5) or TikTok 1080×1920 (9:16 vertical) with safe-area overlay protection.

Idempotent Session Initialization

Clears residual session state and establishes a fresh operational memory block keyed by the conversation tracking ID.

Telegram Bot API Payload Validation Aspect-Ratio Locking Session Idempotency
STAGE 2 · AI NARRATIVE & PROMPTS [ENGINE: GOOGLE GEMINI AI]

AI Narrative & Visual Metadata Generation

An AI Copywriting Strategist analyzes the core topic and brand guidelines to author an editorial carousel deck in Italian. The schema enforces a high-converting hook cover, 3-6 progressive value points (<150 characters for visual legibility), a closing CTA, and a complementary English 3D hero prompt.

Curated Editorial Copywriting

Synthesizes high-converting Italian copy with semantic highlight tags, punchy headlines, and disciplined character budgets.

Isolated 3D Prompt Engineering

Authors optimized English prompt requesting a centered 3D hero object on pure solid white background to facilitate neural extraction.

Google Gemini AI Italian Editorial NLP Hook & CTA Synthesizer Isolated 3D Prompting
STAGE 3 · VISUAL ASSET SYNTHESIS [NEURAL: REMBG & DIFFUSION]

Visual Asset Generation & Foreground Isolation

Dispatches the visual prompt to a generative imagery service for a high-definition 1080×1080 centered 3D hero subject. The raw graphic streams into staging disk and undergoes deep-learning background segmentation (rembg) to output an alpha-transparent PNG.

Resilient Streaming & Backoff

Enforces 45-second execution timeout with exponential backoff up to 2 retry attempts to guarantee network resilience.

3-Tier Segmentation Cascade

Cascade: Primary neural segmentation (rembg) ➔ Secondary system utilities ➔ Tertiary raw visual pass-through (zero crash guarantee).

Cloud Generative Vision rembg Neural Segmentation Alpha Transparency Cutout 3-Tier Fallback Cascade
STAGE 4 · COVER MOCKUP & STAGING [COMPOSITOR: PUPPETEER HIGH-DPI]

Cover Mockup Rendering & Review Staging

Renders a single high-fidelity cover slide using a headless browser compositor at 2× pixel density, applying dynamic brand tokens (Default: Light Theme). Publishes a live, dual-part interactive dashboard to the chat: a rendered cover mockup photo and a full text draft with inline control buttons.

2× High-DPI Lossless Compositing

Headless Chromium renders HTML/CSS layouts at 2x pixel density to guarantee crisp vector typography and lossless visuals.

Zero-Clutter In-Place Updates

Records chat message tracking IDs to edit existing media and text in place during iterations, eliminating chat clutter.

Headless Chromium 2× High-DPI Compositor In-Place Media Update Telegram Inline Keyboard
STAGE 5 · USER REVIEW & FINE-TUNING [STATE MACHINE: EVENT LOOPS]

User Review, Fine-Tuning & State Loops

The session enters an event-driven wait state where the creator can perform iterative modifications before production: toggling Light ☀️ / Dark 🌙 themes, triggering visual regenerations ("Rigenera Copertina"), overriding prompts via `/setimage`, or editing individual slide copy (AI or manual).

Instant Theme Switch Loop

Switches between obsidian black and warm off-white tokens; re-renders the cover mockup and updates the chat in-place.

Multi-Mode Slide Editing

Supports AI slide rewriting within character bounds or manual text submission with automated title and body parsing.

Event-Driven State Machine Light / Dark Theme Tokens Context-Aware AI Rewriter Telegram Callback Queries
STAGE 6 · PRODUCTION RENDERING [BATCH: LOSSLESS ALBUM]

Full Production Rendering & Album Assembly

Upon clicking "Genera Carosello", the compositor initializes production viewports configured for Instagram 1080×1350 (4:5) or TikTok 1080×1920 (9:16 safe areas). Sequentially iterates across all slides, applies the active theme CSS class, captures transparent-edge PNG snapshots, and bundles the ordered media album.

TikTok Safe-Zone Layout Engine

Enforces responsive margins ensuring headlines and copy never collide with native app overlays (captions, sounds, side buttons).

Ordered Album Assembly

Validates 100% slide asset availability and compiles lossless PNG frames into an ordered native carousel collection.

Multi-Slide Batch Engine TikTok Safe-Zone Engine Lossless PNG Compositing Native Album Packager
STAGE 7 · DELIVERY & PURGE [LIFECYCLE: ZERO-FOOTPRINT]

Delivery, Ephemeral Cleanup & Lifecycle Completion

Streams the entire slide collection as a native multi-page carousel photo album directly to the creator. Dispatches completion telemetry, deletes temporary staging messages to leave a pristine chat history, unconditionally wipes staging disk files, and destroys the session in memory.

Native Photo Carousel Dispatch

Streams media as high-resolution photo album cards directly into the recipient's chat for instant one-click publishing.

Guaranteed Finally-Block Purge

Bound to an unconditional finally block ensuring all intermediate HTML, raw graphics, isolated PNGs, and session states are erased.

Telegram MediaGroup API Native Photo Album Dispatch Guaranteed Finally Block Zero-Footprint Purge
